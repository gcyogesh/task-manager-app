# Task Manager App

A simple command-line task manager used to demonstrate version control, commits and releases on GitHub.

## Features (v1.0.0)
- Add a task
- List all tasks
- Mark a task as complete

## Getting Started
```bash
git clone https://github.com/gcyogesh/task-manager-app.git
cd task-manager-app
node app.js
```
